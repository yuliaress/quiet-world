# QUIET WORLD

픽셀아트 감성의 집중·루틴 관리 웹 앱입니다. 타이머, 오늘 할 일, 반복 루틴, 하루 기록, 기분, 수집 조각을 브라우저에서 직접 관리할 수 있습니다. 데이터는 현재 브라우저의 `localStorage`에 저장되며 계정이나 서버로 전송되지 않습니다.

## 실행

프로젝트 폴더에서 로컬 서버를 실행한 뒤 브라우저에서 `http://localhost:8000`을 여세요.

```powershell
py -m http.server 8000
```

VS Code의 Live Server 확장을 사용해 `index.html`을 열어도 됩니다. 월드 캐릭터 이미지를 캔버스에 표시하려면 로컬 서버로 실행하세요.

## 동작

- 타이머는 시작·일시정지·재개·정지를 지원하며 새로고침 후에도 진행 중인 세션을 이어갑니다.
- 할 일은 추가·수정·완료·삭제할 수 있고 기록과 함께 날짜별로 관리됩니다. 루틴은 추가·수정·삭제 후 반복해서 사용하며 매일 완료 상태가 초기화됩니다.
- 할 일 완료와 루틴 완료로 조각을 모으고, 책 수집·집중 시간·루틴 수행에 따라 오늘의 배지가 열립니다.
- 오른쪽의 기분을 눌러 오늘의 상태를 바꿀 수 있습니다.

## 구성

- `index.html`: 페이지 마크업과 스타일·스크립트 연결
- `css/styles.css`: 레이아웃, 패널, 반응형 스타일
- `js/`: 타이머, 기록, 조각, 할 일, 월드 렌더링 기능
- `assets/player.png`: 월드 캐릭터 스프라이트
- `README.dev.md`: 파일별 역할과 유지보수 안내
