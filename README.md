# QUIET WORLD

## 현재 버전 · 3.0 · 시간대 광석

작은 행동과 집중으로 광석을 모아 나만의 방을 가꾸는 개인용 웹앱이에요. 첨부한 픽셀 광석 7종을 사용해요. 가구와 마이는 색상 블록으로 표현하며, 이전 화면 코드는 보관하되 실행하지 않아요.

- **오늘**: 분야를 선택하는 할 일, 매일 반복하는 루틴, 이어지는 집중 타이머, 기분, 일회성 노트 발견을 이용해요.
- **내 방**: 4종 가구 제작, 32칸 배치, 이동·회수, 편집 저장·취소를 지원해요.
- **기록**: 날짜별 활동·기분·집중 시간·광석 지급 내역을 돌아보고 회고를 저장해요. 집중 지급 내역은 20개씩 넘겨 볼 수 있어요.
- **수집과 설정**: 7종 잔액·시간대 획득표·확률표·회색 교환소·배지·가구 도감, 백업·복원과 설치 안내가 있어요.
- **집중 5분마다 5–25개**를 추첨해요. 15–19개 45%, 10–14개 20%, 20–24개 20%, 5–9개 10%, 25개 5%이며 구간 안 정수는 균등해요. 평균은 16.4개이고 하루 지급 한도는 없어요.
- 기기 현지 시각에서 00–04시 남색, 04–08시 파랑, 08–12시 초록, 12–16시 노랑, 16–20시 주황, 20–24시 보라예요. 각 5분이 완성된 시각으로 색을 정해요.
- 남은 집중 시간은 휴식·종료·재방문과 자정 후에도 이어져요. 실행 중 앱을 닫으면 돌아왔을 때 경과한 각 구간의 색으로 정산해요. 추첨은 저장 재시도에도 같은 결과가 나와요.
- **회색 광석**은 분야별 할 일 첫 완료 +5(최대 30개/일), 루틴 +5(최대 10개/일), 노트 한 번 +5예요. 회색 1개를 원하는 색 1개로만 교환해요. 취소·삭제·재생성으로 지급 한도를 되돌리지 않아요.
- 개인 기록은 같은 브라우저에 남아요. 기기 간 자동 공유·계정·결제는 없어요. 백업 파일로 옮길 수 있어요.
- 이전 기록이 있으면 백업 후 이전 안내가 나타나요. 원래 저장 내용은 자동으로 삭제하지 않아요.
- v2와 초기 버전의 잔액은 생기→초록, 집중→파랑, 메아리→보라, 흐름→남색, 반짝임→노랑, 연결→주황의 **10배**로 전환해요. 가구 비용도 10배로 맞춰 구매력을 유지하고 기록·가구·노트 배지를 보존해요. 기존 집중에 소급 지급하지 않아요.
- 38개 검사(기존 기능 22개 + 광석 전용 16개)로 경계·추첨·긴 세션·중복·교환·동시 저장·실패·이전·오프라인·작은 화면을 확인해요.

현재 실행은 `npm run dev`, 동작 검사는 `npm test`예요. 검사는 Playwright가 미리 설치된 작업 환경에서 실행하도록 되어 있어요. 공개용 정적 파일 준비 명령은 `npm run build`이며 실제 공개는 별도 승인이 필요해요.

기능·규칙과 판매 준비 제안은 `.baze-files/outputs/QUIET-WORLD-기능과-판매준비.md`에 정리했어요.

## 아래는 이전 버전 설명이에요

픽셀아트 감성의 생활 보조형 게임입니다. 타이머, 오늘 할 일, 반복 루틴, 하루 기록, 기분, 수집 조각을 관리하고, 모은 재료로 나만의 방을 꾸밀 수 있습니다. 데이터는 현재 브라우저의 `localStorage`에 저장되며 계정이나 서버로 전송되지 않습니다.

## 실행

프로젝트 폴더에서 로컬 서버를 실행한 뒤 브라우저에서 `http://localhost:8000`을 여세요.

```powershell
py -m http.server 8000
```

VS Code의 Live Server 확장을 사용해도 됩니다. PWA 설치와 오프라인 플레이는 `localhost` 또는 HTTPS 서버에서 제공됩니다.

## 동작

- 타이머는 시작·일시정지·재개·정지를 지원하며 새로고침 후에도 진행 중인 세션을 이어갑니다.
- 할 일은 추가·수정·완료·삭제할 수 있고 기록과 함께 날짜별로 관리됩니다. 루틴은 추가·수정·삭제 후 반복해서 사용하며 매일 완료 상태가 초기화됩니다.
- 할 일 완료와 루틴 완료로 조각을 모으고, 책 수집·집중 시간·루틴 수행에 따라 오늘의 배지가 열립니다.
- 오른쪽의 기분을 눌러 오늘의 상태를 바꿀 수 있습니다.
- 메인 화면이 나만의 방입니다. 소품을 제작해 배치하고, 배치한 소품을 눌러 보관함으로 회수할 수 있습니다. 재료와 방 배치는 날짜가 지나도 보존됩니다.
- 지원 브라우저에서는 앱을 설치할 수 있으며, 최초 온라인 실행 후 앱 파일이 캐시되어 오프라인에서도 사용할 수 있습니다. 오프라인 기능은 `localhost` 또는 HTTPS에서 제공됩니다.

## 구성

- `index.html`: 페이지 마크업과 스타일·스크립트 연결
- `css/styles.css`: 레이아웃, 패널, 반응형 스타일
- `js/`: 타이머, 기록, 조각, 할 일, 방 꾸미기, PWA와 이전 월드 렌더링 기능
- `manifest.webmanifest`, `service-worker.js`: 앱 설치 정보와 오프라인 캐시
- `assets/player.png`, `assets/app-icon.svg`: 월드 캐릭터 스프라이트와 앱 아이콘
- `README.dev.md`: 파일별 역할과 유지보수 안내
