# QUIET WORLD 개발 메모

이 문서는 프로젝트 구조와 기능을 수정할 때 참고할 개발용 안내입니다. 사용자에게 보이는 프로젝트 개요와 실행 방법은 `README.md`를 확인하세요.

## 파일별 책임

| 파일 | 책임 |
| --- | --- |
| `index.html` | 페이지 구조와 에셋/스크립트 연결 |
| `css/styles.css` | 디자인 토큰, 공통 패널, 좌·중앙·우측 영역, 반응형 레이아웃 |
| `js/timer.js` | 집중 타이머의 시작/일시정지/정지 동작 |
| `js/day-log.js` | 오늘 기록 목록과 펼치기 동작. `window.addDayLog()` 제공 |
| `js/fragments.js` | 조각 표시와 책 줍기/지나치기 상호작용 |
| `js/todos.js` | 할 일 표시, 완료 상태, 진행률 업데이트 |
| `js/world.js` | 타일 맵, 키보드 이동, 픽셀 월드 캔버스 렌더링 |
| `assets/player.png` | 플레이어 애니메이션 스프라이트 시트 |

## 수정 원칙

- 화면 문구와 구조는 `index.html`, 시각 표현은 `css/styles.css`, 상호작용은 해당 기능의 `js/` 파일에서 수정합니다.
- 스크립트는 `index.html`에 선언된 순서대로 로드합니다. `fragments.js`는 앞서 로드되는 `day-log.js`의 `window.addDayLog()`를 사용합니다.
- `world.js`에서 맵 타일 크기와 캔버스 크기를 함께 확인하고, 캐릭터 이미지 경로는 프로젝트 루트 기준으로 지정합니다.
- 빌드/패키지 매니저는 설정되어 있지 않습니다. 변경 후 로컬 서버로 페이지를 열고 각 기능과 브라우저 콘솔을 확인합니다.
